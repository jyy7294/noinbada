# 2026년 6~7월 근거 기반 재구성 사건 seed

이 폴더는 2026-06-01~2026-07-31 한국 트렌드 MVP 재생을 위한 **사건 시점 참고 데이터**입니다. 공식 일정·차트·통계, 당사자 발표, 날짜가 확인되는 언론 보도를 바탕으로 대표어와 활성 구간을 재구성했습니다.

## 중요한 경계

- `provenance`: `research_reconstructed`
- `measurement_status`: `event_timing_evidence_only`
- `rank_eligible`: `false`
- 검색량, X 순위, Google Trends 순위를 만들거나 추정하지 않았습니다.
- 따라서 이 파일만으로 당시 플랫폼 순위나 관심도 크기를 주장할 수 없습니다.
- 실제 관측 원장과 결합할 때도 관측값으로 재표기하지 말고, 별도의 재구성 데모/사건 사전으로 사용해야 합니다.

## 파일

- `events.jsonl`: 사건 1개당 1행
- `manifest.json`: 기간, 건수, 카테고리 분포, 사용 제한

## 핵심 필드

| 필드 | 의미 |
|---|---|
| `representative_term` | 근거 자료에서 직접 확인되는 대표 사건·제품·작품·행사명 |
| `aliases` | 동일 사건을 찾기 위한 관련 표현, 최대 5개 |
| `active_from`, `active_to` | MVP에서 사건을 노출할 수 있는 근거 기반 활성 구간 |
| `peak_hint` | 공개일·행사일·차트 기준일 등 가장 강한 날짜 단서 |
| `evidence` | URL, 발행일, 발행처, 근거 유형, 해당 근거가 지지하는 주장 |
| `confidence` | 사건명·시점 확인 신뢰도. 플랫폼 인기도 신뢰도가 아님 |

## 사용 예

1. 실제 X·Google 관측에서 나온 대표어/별칭과 이 사건 사전을 매칭합니다.
2. 관측값이 있는 경우에만 실제 순위 계산에 넣습니다.
3. 관측값이 없는 항목은 데모 재생의 후보 또는 검수용 정답셋으로만 사용합니다.
4. 회사 연결은 이 데이터와 분리해 공식 IR·공시·제품·공급·유통 근거를 추가 검수합니다.
