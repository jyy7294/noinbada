# TRZIP 설문 및 제품 가설

## 검증할 핵심 가설

1. 주식은 수익 활동이면서 주변 권유, 수익 인증, 손실 밈을 통해 확산되는 대중문화이기도 하다.
2. 사용자는 익숙한 소비·문화 트렌드를 기업 탐색의 첫 단서로 사용할 수 있다.
3. 단기 화제성만으로는 신뢰가 부족하며, 지속기간과 실제 과거 시장반응을 함께 보고 싶어 한다.
4. 관련기업 목록은 수익을 보장하는 추천이 아니라 탐색 후보여야 하며, 관계 근거와 위험을 분리해야 한다.

## 설문 문항

1. 주변 사람이 주식을 권하거나 수익 인증을 보여줘 주식을 시작해 본 적이 있습니까?
   - 있다 / 관심만 생겼다 / 없다
2. 현재 주식투자를 하고 있습니까?
   - 계속 투자 중 / 가끔 투자 / 중단 / 시작한 적 없음
3. 중단 또는 미시작 이유는 무엇입니까? 복수 선택
   - 손실 경험 / 물려 있음 / 무엇을 살지 모름 / 정보가 어려움 / 자금 부족 / 관심 부족 / 기타
4. 평소 알고 있던 유행이 특정 기업의 매출이나 주가에 연결된 사례를 본 적이 있습니까?
   - 직접 수익 경험 / 사례만 봄 / 없음 / 잘 모르겠음
5. 트렌드 관련 기업을 볼 때 가장 필요한 기준은 무엇입니까? 최대 3개
   - 트렌드 지속기간 / 기업과의 직접 관계 / 공급망·유통 관계 / 과거 수익률 / 거래량 변화 / 재무 안정성 / 위험 요인
6. 수익률이 아닌 좋아요가 많은 밈트폴리오를 얼마나 신뢰하겠습니까?
   - 1점 전혀 신뢰하지 않음 ~ 5점 매우 신뢰함
7. 검증된 관계, 지속기간, 과거 시장반응이 함께 제공되면 기업 상세를 확인할 의향이 있습니까?
   - 1점 전혀 없음 ~ 5점 매우 높음
8. 서비스에서 기업을 확인한 뒤 실제로 하려는 행동은 무엇입니까?
   - 기업 상세 확인 / 관심종목 저장 / 추가 검색 / 소액 매수 검토 / 행동하지 않음

## 해석 원칙

- “수익이 날 법한 종목” 의향 질문만 단독으로 묻지 않습니다. 응답자를 유도하고 투자 추천 기대를 과장하기 때문입니다.
- 과거 수익률은 지속가능성의 증거가 아니라 사후 시장반응입니다.
- 제품의 핵심 전환은 `트렌드 확인 → 관계 근거 확인 → 기업 상세 확인`입니다.
