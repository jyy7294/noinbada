# TR ZIP 모바일 화면의 Lucian 요소

기준일: 2026-10-14. 기존 TR ZIP의 보라색 브랜드, 다이얼과 목록, 실제 데이터
흐름을 유지하며 아래 세 요소의 조작과 피드백을 화면에 맞게 적용합니다.
Lucian 전체 갤러리나 별도의 UI 프레임워크를 제품에 포함하지 않습니다.

## 기존 테마와 접근성

`--ux-*` 색상은 TR ZIP의 기존 테마 변수에 연결합니다. 다음은 매핑 예입니다.
선택 요소가 참조하는 토큰을 모두 정의하고, 기존 TR ZIP의 글꼴을 상속합니다.
현재 화면은 로컬 Wanted Sans Variable을 사용하며 별도의 외부 폰트 요청을
추가하지 않습니다. 글꼴 고지는 [Wanted Sans OFL](licenses/WANTED-SANS-OFL.txt)에
별도로 보존합니다.

```css
.ux {
  --ux-accent: var(--purple);
  --ux-accent-soft: var(--soft);
  --ux-line: var(--line);
  --ux-ink-2: var(--muted);
  font-family: inherit;
}
```

원본 토큰의 라이트·다크 기본색을 페이지 전체에 덮어쓰지 않습니다. 현재 제품은
기존 라이트 화면을 유지하며 자동 다크 테마 전환은 추가하지 않았습니다. Lucian
원본의 두 테마 지원을 제품의 다크 모드 완료로 표현하지 않습니다. 보라색 선택
상태, 읽을 수 있는 대비, 명확한 포커스를 유지합니다.
버튼은 실제 터치 영역이 최소 44×44 CSS px가 되도록 하고, 아이콘에는 한국어
접근 가능한 이름을 제공합니다. Dial/List는 실제 보기 선택 상태를 `aria-pressed`로
표시하며 토스트는 `aria-live`로 실제 결과를 알립니다.

`prefers-reduced-motion: reduce`에서는 전환을 즉시 끝내고 반복 장식을 멈추며
검색, 보기 전환과 저장 기능을 그대로 사용할 수 있어야 합니다. 버튼의 포커스와
native 대화상자의 닫기·포커스 복귀도 보존합니다.

## 실제 동작에 연결하는 조건

- 기존 `trzip.saved.v2` 저장 값을 유지합니다. 저장·해제 안내는 `localStorage`
  쓰기가 성공한 다음 표시합니다. 저장 실패를 성공처럼 표시하지 않고 실패 전의
  상태를 보존합니다. 샘플 저장 수, 계정 동기화나 서버 저장을 암시하는 안내를
  추가하지 않습니다.
- 검색은 현재 실제 게시본의 제목과 확인된 기업명에 연결합니다. 새 화면에서도
  상세 요청은 목록의 `publication_id`를 유지하며, 검색·보기 전환은 순위를
  재점수하지 않습니다. 기존 읽기 전용 API와 응답 형식은 변경하지 않습니다.
- 외부 기사·출처·상장·관계 근거 링크는 `safeURL`에서 HTTP/HTTPS만 허용하고
  HTML에 들어가는 데이터는 이스케이프합니다. 새 창 링크의 `noopener noreferrer`를
  유지합니다. 이미지 실패와 API 오류는 실제 상태로 안내합니다.
- 원본 #070에는 초기 `push('info'); push('ok')` 샘플 알림과 `wait`를 일정 시간
  뒤 임의 성공으로 바꾸는 타이머가 있습니다. 둘 다 제품에 포함하지 않습니다.
  #027과 #039의 하드코딩 샘플 목록도 제거합니다. 실제 완료 결과가 없는 동안
  시간만으로 성공을 생성하지 않습니다.
- 갤러리의 별도 자동 시연 드라이버는 원본 요소 파일에 포함되지 않습니다.
  다만 요소 안의 샘플 데이터·초기 시연 호출은 별개이므로 위 조건으로 제거합니다.
  토스트 자동 닫힘과 승인된 데이터 갱신 타이머는 실제 동작이며 가짜 시연과 다릅니다.
- 이벤트 리스너·타이머·관찰자가 화면 전환이나 재초기화로 중복되지 않도록 합니다.
  자율 회전, 가짜 라이브 시각, 임의 점수, 불필요한 무한 애니메이션을 추가하지 않습니다.

## 검증 상태와 완료 조건

원본 다운로드, 카탈로그 버전·해시 일치, CDN·커밋 미러 일치와 MIT 원문 보존은
확인했습니다. 아래 화면 검증 결과는 실제 구현 및 브라우저 QA 후 갱신합니다.

- 375px·390px·430px 모바일과 PC 화면에서 가로 넘침, 손가락 드래그와 세로
  스크롤 충돌, 검색 키보드 표시, safe-area와 상세·바텀시트를 확인합니다.
- 실제 API에서 받은 목록 → 같은 게시본의 상세 → 기업 관계·상장·출처 링크를
  확인합니다. 자료가 없거나 지연될 때 가짜 트렌드로 채우지 않습니다.
- 저장 → 새로고침 → 유지 → 해제, 현재 목록에서 벗어난 저장 항목, 저장 실패와
  잘못된 기존 저장값의 복구를 확인합니다.
- 키보드만으로 검색·Dial/List·저장·대화상자 닫기를 사용하고 포커스 위치와
  스크린리더 이름·상태 안내와 동작 감소 상태를 확인합니다. OS의 다크 선호 상태에서도
  제품의 라이트 화면과 조작을 유지하는지 확인합니다. 실제 다크 테마 전환은 미구현입니다.
- JavaScript 구문, HTML/DOM 연결, 콘솔 오류, 관련 런타임 회귀를 확인합니다.
  UI 변경 이후의 화면·코드 해시를 다시 기록합니다. 기존 화면 QA를 새 코드의
  검증으로 재사용하지 않습니다.
- 화면 변경과 정식 전환은 구분합니다. 공개 후보의 화면을 검증해도 기존 72시간
  운영 게이트와 준비된 Vercel 배포의 코드 일치 조건을 그대로 충족해야 합니다.

원본 작업 파일은 gitignored `work/lucian/`에 있습니다. 제품 실행 중 원본을
다운로드하거나 설치 명령을 실행하지 않습니다.

### 2026-10-14 의미 검토

새 화면 코드의 읽기 검토에서 검색·보기 전환이 수집 순위나 공급원 개수를 바꾸지
않고, 기업 근거가 선택한 트렌드의 동일 게시본에 연결된 것을 확인했습니다.
공개 API 표본은 Google 전체 공개 목록 196개였으며 목록과 기업 연결이 있는
상세 응답의 게시본이 일치했습니다. 이 개수는 해당 조회 시점의 값이며 고정 목표가
아닙니다. 외부 링크의 HTTP/HTTPS 제한, 자격 증명 포함 URL 거부, 데이터 이스케이프와
같은 출처 이미지 경로 제한도 읽기 검토로 확인했습니다.

이 검토는 브라우저 QA나 전체 회귀 테스트 통과를 대신하지 않습니다. 상세 캐시의
최신성 재검증, 실제 기업 연결이 없을 때의 안내, 토스트 닫기 터치 처리는 구현
담당에게 확인·수정 사항으로 전달했습니다.

위 세 사항을 수정했습니다. 전체 로컬 시험 655 passed/1 skipped와 Linux CI가 통과했고,

로컬에서 실제 저장·해제·재접속과 저장 결과 알림을 확인했으며 초기 샘플 알림은 발생하지 않습니다.
동작 감소 설정에서 탭 표시와 다이얼 전환 시간이 0초이고 콘솔 오류는 없었습니다.
