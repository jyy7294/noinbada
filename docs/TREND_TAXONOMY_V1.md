# TRZIP 한국 트렌드 분류체계 V1

## 귀납 근거

Google 한국 올해의 검색어 2024~2025 사례를 분야와 후속 행동으로 다시 분류했다. `APT.·밤양갱`은 음악에서 밈·따라하기로, `파묘·오징어 게임`은 시청에서 IP 소비로, `ChatGPT·뤼튼`은 도구 사용으로 확장됐다. 반면 선거·사건·행정 신청은 관심도가 높아도 소비문화 메인과 분리해야 했다.

## 메인 분야 카테고리

1. `food_culinary`: 음식, 메뉴, 레시피, 외식, 식품 브랜드
2. `music_performance`: 노래, 아티스트 활동, 안무, 팬덤 확산
3. `screen_content`: 영화, 드라마, 예능, 캐릭터, 콘텐츠 IP
4. `product_brand`: 제품, 브랜드, 굿즈, 기기
5. `fashion_beauty`: 패션, 뷰티, 스타일
6. `gaming_digital`: 게임, 디지털 놀이
7. `place_experience`: 팝업, 여행, 공간, 방문 경험
8. `lifestyle_behavior`: 운동, 취미, 생활방식
9. `participation_meme`: 밈, 챌린지, 따라하기, 공유 형식
10. `technology_tool`: AI·앱·서비스의 실제 채택
11. `wellness_behavior`: 건강 관리 행동과 식습관
12. `seasonal_food_ritual`: 복날 음식처럼 계절과 소비 행동이 결합된 현상
13. `sports_attendance`: 경기 결과가 아니라 예매·방문·응원·굿즈·먹거리로 이어지는 관람 행동
14. `fashion_collectible`: 키링·인형·굿즈처럼 소장·꾸미기·교환 행동이 동반되는 패션형 수집물

## 승격 조건

순위의 트렌드명은 X·Google에서 실제 관측된 대표어를 유지한다. `말복`을 `말복 삼계탕·보양식 소비`처럼 해석 문장으로 바꾸지 않는다. 대신 `왜 뜨는가`에 삼계탕·보양식·외식 관심 증가를 별도로 기록한다.

## 분리 레인

- `issue`: 정치, 정책, 행정 신청, 사건, 사고, 재난, 논란, 단순 경기 결과
- `review`: 일반명사, 동명이인, 의미 불명, 후속 행동 맥락 미확인
- 내부 후보는 삭제하지 않는다. 새로운 맥락이 확인되면 재분류한다.
