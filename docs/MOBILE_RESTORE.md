# TR ZIP 기존 모바일 화면 복원

2026-10-14. 사용자가 선택한 원래 `frontend/index.html`의 모바일 다이얼을
현재 운영 API와 연결합니다. 서버의 수집 관찰 원장은 계속 사용합니다.

## 화면과 사용자 흐름

- 기존 보라색 #7B3FF2, Wanted Sans, 왼쪽 큰 키워드와 오른쪽 세로 다이얼을 사용합니다.
- Dial이 기본입니다. 드래그·키보드 위/아래·키워드 선택으로 이동하고 큰 키워드에서 상세를 엽니다.
- List는 같은 주요 목록입니다. 전체 탐색에서는 실제 전체 목록·기업 연결·사회 이슈를 검색합니다.
- 상세 → 관계 종류별 기업 폴더 → 선택 트렌드의 기업 근거 바텀시트로 이어집니다.
- 뒤로 가기에서 다이얼 선택·검색어·화면 스크롤을 보존하고 시트 닫기 후 기업 버튼으로 초점을 돌립니다.
- 원래 마이페이지 진입 위치에서 브라우저에 저장한 트렌드를 확인합니다.
  계정·커뮤니티·밈트폴리오 제작과 새 하단 탐색바는 포함하지 않습니다.
- 휴대전화는 기기 테두리와 가짜 상태바 없이 전체 너비를 사용하고, PC는 480px 앱을 중앙에 표시합니다.

## 데이터·저장·출처

현재 읽기 전용 API와 게시 식별자를 유지합니다. 목록과 상세가 같은 게시본이어도
최신성과 24시간 기업 만료는 서버 시각으로 재평가하므로 상세 응답을 영구 캐시하지 않습니다.
기업 조회 API의 기업 신원과 선택한 트렌드의 관계 근거를 구분합니다. 다른 트렌드에
먼저 나온 같은 기업의 근거로 선택한 관계를 덮어쓰지 않습니다.

`trzip.saved.v2`와 기존 다른 저장 키를 보존합니다. 저장 성공 이후에만 UI 상태와
완료 알림을 변경합니다. 저장 공간 오류 또는 해석할 수 없는 기존 데이터는 안내하고
덮어쓰지 않습니다. 현재 목록에서 벗어난 항목은 저장한 제목으로 별도 표시합니다.

API에 없는 가격·수익률·인기도·점수를 생성하지 않습니다. 이전 시연 원본의
브라우저 시계·재구성 그래프·모의 종목·React 로더·동적 코드 실행을 옮기지 않습니다.
현재 실제 관측 시각·수집 지연·기업 확인 상태·공식 이미지 출처를 표시합니다.

[Lucian 적용 기록](LUCIAN_COMPONENTS.md)의 #027/#039/#070에서 작은 조작·피드백만
포팅했습니다. 전역 스킬 설치와 런타임 의존성을 추가하지 않았습니다.

Wanted Sans v1.0.3은 [공식 원본](https://github.com/wanteddev/wanted-sans/tree/v1.0.3)을
사용해 `/wanted-sans.woff2`에서 직접 제공합니다. 원본 SHA-256은
`4259e7e9a172e634c2cb419d793b84148990316341e910443e5d10965b2c8f16`이며
[OFL 원문](licenses/WANTED-SANS-OFL.txt)을 보존했습니다. 글꼴에 Git 텍스트 변환을
적용하지 않습니다. API의 정적 파일 허용 목록과 배포 검증 해시에 글꼴도 포함합니다.
기존 self-only CSP를 유지합니다.
