# TRZIP X + Google 제품 정책 V1

단일 페르소나, 트렌드 70%·기업 해석 30% 정보구조, KPI와 발표 흐름은 `PRODUCT_DIRECTION_TRANSCRIPT.md`를 따른다.

## 결론

TRZIP의 트렌드 발견·순위·연관 키워드는 X와 Google Trends만 사용한다. YouTube, NAVER, Instagram, 뉴스 본문은 이 경로에 들어올 수 없다. 관련 기업은 플랫폼이 주는 답을 쓰지 않고 TRZIP이 별도 근거로 판단한다.

## 공개 레인

- `main`: 소비·생활·문화 전반의 Top 10. 음식·외식, 제품·브랜드, 쇼핑·유통, 패션·뷰티, 주거·생활용품, 건강·웰니스, 여행·공간, 취미·수집, 스포츠·운동, 음악·공연, 영상·출판, 게임·디지털, 밈·참여, 계절 소비를 포함한다.
- `issue`: 정치, 범죄, 사고, 재난, 갈등, 단순 날씨, 속보성 인물 이슈
- `review`: `수건`처럼 맥락 없는 일반명사, 식별되지 않은 이름, 의미가 불명확한 후보

모든 후보는 내부에 남긴다. 분류는 삭제 규칙이 아니라 공개 위치 결정이다.

## 순위

`최종점수 = X·Google RRF 60% + 상승속도 20% + 지속성 15% + 양쪽 동시관측 5%`

- 원시 검색량을 서로 더하지 않는다.
- 한 플랫폼에서만 잡힌 주제도 공개할 수 있으며 단독 관측임을 표시한다.
- 별칭을 하나의 사건으로 정규화한 뒤 순위를 매긴다.
- 사용자는 네 점수 구성과 양쪽 원순위를 볼 수 있다.

## 관련 키워드

최대 5개다. 실제 X 동시출현 표현 또는 Google 관련·급상승 검색어는 출처를 표시한다. 데모의 재구성 키워드와 운영자 검토 후보는 명시적으로 구분하며, 출처가 검증되지 않은 후보는 순위 근거로 사용하지 않는다.

## 관련 기업

OpenDART, 기업 IR, 공식 제품·소유·공급·유통·후원·규제 자료를 근거로 `direct`, `indirect`, `sector_watch`, `excluded`로 분류한다. pykrx는 국내 종목명과 일별 OHLCV 참고자료만 담당하며 기업 관계 판정에는 사용하지 않는다. 단순 단어 유사성은 관계가 아니다.

## 데모 데이터

데모 백필은 2026-05-01 00:00부터 2026-08-12 11:00 KST까지 매시간 생성한다. 이후 시간에는 생성값을 금지하고 실측만 저장한다. 모든 행은 `observed` 또는 `generated`를 가지며 생성값을 실측 검색량으로 표현하지 않는다.

## Trends MCP 운영 경계

Trends MCP 자동 호출은 중지한다. 과거 1회 기능 검증 결과만 참고자료로 남기고 운영 수집·순위·키워드에는 참여시키지 않는다. Google은 대한민국 `geo=KR` 원천을 직접 수집하며 X에도 Trends MCP를 사용하지 않는다. 보관 중인 API 키가 있더라도 코드·문서·로그·Git에는 기록하지 않는다.

## 대한민국 지역 게이트

공개 후보는 대한민국 지역이 증명된 관측만 허용한다. Google은 `geo=KR`을 사용하고, X는 설치된 Chrome으로 `https://x.com/explore/tabs/trending`을 직접 열어 화면에 표시된 대한민국 번호 순위를 수집한다. X API·WOEID·추정 데이터는 사용하지 않는다. YouTube·NAVER·Instagram은 수집·Top10·키워드·점수에 참여하지 않는다.

한국 플랫폼 비교 화면은 임의의 Top10 절단을 하지 않고 각 공식 응답이 반환한 마지막 항목까지 표시한다. 종합 순위는 `RRF(k=60)`로 계산하고 원시 검색량·조회수·언급량을 플랫폼 간 합산하지 않는다. 연결 플랫폼이 하나면 반드시 단일 소스 종합 순위로 표시한다.

제품의 관측원은 X 실시간 트렌드와 Google Trends 대한민국 두 개뿐이다. X는 매시 현재 순위를 스냅샷으로 저장해 자체 지속성·상승속도를 계산하며 제공되지 않는 과거치를 추정하지 않는다.
